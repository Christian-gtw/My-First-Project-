## Programs
| File | Description |
|------|-------------|
| `SimpleCalculator.java` | Takes two numbers and an operator (+, -, *, /) and displays the result |
| `AverageCalculator.java` | Takes four examination scores and displays their average |
| `ItemCost.java` | Takes quantity and unit price and displays the total cost |

## Requirements
- Java Development Kit (JDK) 8 or higher

## How to compile and run
Open a terminal in the project folder, then run:

```
javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
```

## Sample run (ItemCost)
```
Enter quantity of items: 6
Enter unit price (N): 250
Total cost = N1500.00
```
